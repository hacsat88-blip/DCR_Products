# Solar System Explorer JP

## 概要

銀河風の宇宙空間を背景に、太陽系8惑星を対数スケール軌道で表示するデスクトップ向けの単一 HTML プロトタイプです。  
Three.js、OrbitControls、Tween.js を CDN 読み込みで利用し、惑星クリック時の近接フォーカス、情報ポップアップ、軌道スケール切替、惑星選択プルダウンを備えています。

## ファイル構成

- `index.html`
  - 実行本体です。UI、Three.js シーン、惑星データ、アニメーション、ポップアップを 1 ファイルに集約しています。
- `docs/2026-03-20-solar-system-design.md`
  - 設計仕様です。
- `docs/2026-03-20-solar-system-implementation.md`
  - 実装計画です。

## 使い方

1. `index.html` をモダンブラウザで開きます。
2. マウスドラッグで回転、ホイールでズームできます。
3. 惑星をクリックするか、左上のプルダウンから選ぶとフォーカスします。
4. `リアルスケール / 表示スケール` を切り替えると軌道距離の見え方が変わります。
5. `デフォルト表示に戻す` で初期視点へ戻ります。

## プレビュー

- `preview.png`
  - 現在の見た目を headless で保存した画像です。
- `launch-local.bat`
  - ローカルサーバーを立てて既定ブラウザで開く簡易ランチャーです。

## 注意点

- 外部 API や DB は使っていませんが、Three.js / Tween.js / 惑星テクスチャは外部 CDN を参照します。
- テクスチャ取得に失敗した場合は、フォールバック材質で表示を継続します。
- 対象はデスクトップブラウザです。
