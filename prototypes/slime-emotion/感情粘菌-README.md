# 感情粘菌 — Emotion Slime Mold Network

ニュース・SNSの感情データを「栄養濃度」として粘菌シミュレーターに与え、
感情密度の高い場所へ触腕を伸ばす様子をリアルタイムに可視化する Web アプリ。

---

## ▶ 起動方法

1. **感情粘菌.html** をブラウザ（Chrome / Firefox / Edge）でダブルクリック
2. 画面上部の入力欄にトレンドワードを入力 → 「観察する」ボタン
3. 粘菌の脈管が感情地形を探索し、収束するまでアニメーション表示される

※ インターネット接続不要。完全スタンドアロン動作。

## アルゴリズム（Physarum Transport Network）

```
D_ij(t+1) = D_ij(t) + dt × ( |Q_ij|^μ − r × D_ij(t) )

  D_ij  : 脈管伝導率（脈管の太さに比例）
  Q_ij  : フロー量（キルヒホッフ方程式より算出）
  μ     : 強化指数 = 1.8
  r     : 減衰係数 = 1.5
  dt    : 時間ステップ = 0.013
```

1. 各感情ノードの intensity を栄養濃度として設定
2. K-最近傍法 (K=3) でノード間エッジを生成
3. ラプラシアン行列を構築 → キルヒホッフの圧力方程式を Gauss-Jordan 法で解く
4. フロー量から伝導率を更新（高流量 → 脈管が太くなる）
5. 収束（Δ < 8×10⁻⁵）まで繰り返す（上限 800 ステップ）

## ファイル構成

```
感情粘菌.html        ← メインアプリ（このファイルだけで動作）
感情粘菌-README.md   ← このドキュメント
setup.bat            ← slime-emotion/ サブフォルダへのコピー用スクリプト
```

`setup.bat` を実行すると `slime-emotion\index.html` が作成されます。

## 技術仕様

- 外部ライブラリ・CDN 不要（完全スタンドアロン HTML 単一ファイル）
- Canvas 2D API によるリアルタイム描画
- requestAnimationFrame ベースのアニメーションループ
- 外部 API・個人情報取得なし（モックデータのみ使用）
