# Failure Matrix — 失敗時対応表

**原則: 嘘より Unknown。不確実なら確実に不確実と示す。**

| 状況 | 対応 |
|---|---|
| **データ取得不能** | `[?] Unknown` と明記し、外部確認が必要と付記する |
| **EDINET未接続** | 全項目 [W] で代替、冒頭に `⚠️EDINET未接続(縮退モード)` |
| **EDINETツール呼出失敗** | 1回再試行 → 失敗継続なら web_search にフォールバック（`[W](Fallback)`） |
| **ID解決で複数ヒット** | 証券コード優先で最上位採用し、候補を併記する |
| **ID解決ヒット0件** | 非上場・海外上場の可能性を明記し除外枠へ |
| **可用性 🔴unavailable** | Scoring停止、除外枠に分類する |
| **連続3項目以上でツール失敗** | `🟡[Fix]` に昇格し、重い呼出を控えて縮退分析を完遂する |
| **市場急落・VIX急騰** | `🔴[Stop]` を冒頭表示、個別強評価を避け下振れ幅を広めに設定 |
| **ユーザーが購入確定を求めた** | 「売買命令はしない」旨を伝え、判断材料の確認に変換する |
| **10倍株断定を求められた** | 「10倍株シナリオ現実度」として条件付き仮説に変換する |
| **一次情報が確認できない銘柄** | 候補に残す場合も `🟡要確認` にとどめる |

## 自己制御ルール

- 5銘柄以上の全項目深掘りを求められた場合: **上位3銘柄を詳細、残りは軽量分析**
- value_growth で5〜10社を出す場合: **ランキング表は全件、詳細は上位3件**
- ツール呼出失敗は1回再試行する
- 連続3項目以上で失敗 → `🟡[Fix]` 宣言、縮退分析を完遂する

## Convergence Gate（α2）

出力生成後、reviewer または SKILL.md 側で以下を機械チェックする:

**禁止語リスト: `contracts/safety-protocol.md` の「禁止語」セクションを参照（単一正本）。**

**検出時のアクション:**
1. 出力を表示する前に `🟡[Fix]: Convergence Gate — 禁止語検出` を冒頭に付与
2. 禁止語を含む文を「判断材料の整理」に書き換えて再出力
3. 再出力後も含まれる場合は出力を保留し、ユーザーに確認する
