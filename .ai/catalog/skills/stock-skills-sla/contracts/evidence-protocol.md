# Evidence Protocol — 証拠・源タグ契約

すべての数値・事実・見立てに源タグを付与する。タグなしの数値・株価・制度記述は無効。

## 源タグ4種

| タグ | 意味 | 使用例 |
|---|---|---|
| `[E]` | EDINET DB MCP 由来 | 財務数値・有報・株主・セグメント |
| `[W]` | web_search 由来 | 株価・PER/PBR・決算短信・IR資料 |
| `[L]` | LLM 記憶由来 | 一般知識（数値・株価・制度では **原則禁止**） |
| `[?]` | Unknown / 取得不能 | 確認できなかった項目 |

## 確信度4分割（タグに加えて文中で明示）

| ラベル | 意味 | 例 |
|---|---|---|
| `Fact` | 一次情報で確認済み | 「売上高 120億円 [E:有報2025/03] Fact」 |
| `（推定）` | データからの見立て | 「PER 15倍前後 [W]（推定）」 |
| `（仮説）` | 条件付き筋書き | 「売上 +20% なら PER 再評価余地（仮説）」 |
| `Unknown` | 未確認・取得不能 | 「中計なし [?] Unknown」 |

## EDINET カスケード原則

```
EDINET → IR/TDnet/会社開示を含む web_search → LLM記憶 → Unknown
```

- EDINETで取れる情報は必ずEDINETを優先する
- EDINETツール失敗時: 1回再試行 → web_search へフォールバック（`[W](Fallback)` と明記）
- LLM記憶は定性的な一般知識にのみ使用（`[L]`）。数値・株価・制度・人物には使わない
- SNS・掲示板・まとめサイト・匿名情報は根拠にしない

## EDINET優先ソース

- 財務数値（売上・利益・資産・負債）
- 有価証券報告書
- セグメント情報
- MD&A
- 大株主・政策保有
- 業界内順位

## web_search優先ソース

- 直近株価・出来高
- PER / PBR / PSR / 配当利回り
- 時価総額
- 決算短信・決算説明資料・適時開示・中計
- 指数（日経・TOPIX等）/ VIX / 為替 / 金利

## 鮮度マーカー（Layer 5 で付与）

```
[E:有報2025/03 取得2026-04-29]
[W:決算短信2025/11 確認2026-04-29]
```

## データ不足時の扱い

| 状況 | 対応 |
|---|---|
| 推定軸 1〜2個 | `⚠️推定軸N個` を付け候補に残す |
| 推定軸 3個以上 | 「要追加確認」枠に降格 |
| D軸(ファンダ)が[E]取れず | 推定軸扱い |
| 流動性極低 | `⚠️流動性リスク` を付ける |
| 可用性 🔴unavailable | Scoring停止、除外枠へ |
| EDINET未接続 | 全項目 [W]、冒頭に `⚠️EDINET未接続(縮退モード)` |
