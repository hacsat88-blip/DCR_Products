# Copy Frameworks 共通テンプレ集

`copywriting` / `copy-editing` / `ad-creative` / `email-sequence` / `cold-email` / `social-content` の各スキルが参照する共通フレームワーク。

## PAS（Problem → Agitation → Solution）

```
[Problem]   読み手の現状の問題を正確に名指し
[Agitation] その問題が今後どう悪化するか / 放置のコスト
[Solution]  自社/プロダクトがどう解決するか
```

適用：B2B / SaaS / 課題顕在ターゲット

## AIDA（Attention → Interest → Desire → Action）

```
[Attention] 視覚または数字で目を止める
[Interest]  読み手の文脈に紐づく具体例
[Desire]    便益を「あなた」基準で言語化
[Action]    1つだけの行動指示（CTA）
```

適用：LP / 広告全般 / 入口コピー

## 4U（Useful / Urgent / Unique / Ultra-specific）

ヘッドライン・件名チェックリスト：
- **Useful**：読み手にとって明白な価値
- **Urgent**：今読むべき理由
- **Unique**：他と差別化された角度
- **Ultra-specific**：抽象でなく具体（数字・固有名）

## BAB（Before → After → Bridge）

```
[Before] 読み手の現在の痛み / 制約
[After]  解決後の理想状態
[Bridge] その差を埋める方法 = プロダクト
```

適用：オンボーディング・教育コンテンツ・before/after 訴求

## 心理レバー（strategic-messaging Layer 2 から継承）

| バイアス | 適用例 |
|---|---|
| 社会的証明 | "X社が導入" / "ユーザー数N人" / レビュー |
| 希少性 | 数量限定・期間限定・限定特典 |
| 損失回避 | "今逃すと..." / "失う" 文脈の活用 |
| アンカリング | 高価格を先に提示 → 比較で割安に見せる |
| 互恵性 | 先に価値を渡す（free tool, 無料DL） |

## CTA 規律

- 1ページ / 1メール / 1広告につき主要CTA は **1つだけ**
- 行動動詞で始める（"Get" / "Start" / "Download" / "Book"）
- 視認できる位置（ファーストビュー内 + ページ底）
- ボタン色は本文と対比

## 文字数ガイド

| 媒体 | 推奨 | 上限 |
|---|---|---|
| Email subject | 30-50 chars | 78 |
| Headline (LP) | 5-9 words | 12 |
| Hero subhead | 1-2 sentences | 30 words |
| CTA button | 2-4 words | 5 |
| Twitter/X | 70-100 chars | 280 |
| LinkedIn post | 150-200 chars | 3000 |
| Google RSA headline | 25-30 chars | 30 |
| Google RSA description | 70-80 chars | 90 |
| Meta primary text | 90-125 chars | 125 (mobile cutoff) |

## チェックリスト（提出前）

1. ターゲットの JTBD が明文化されているか
2. 主張に対する証拠（数字 / 引用 / 事例）があるか
3. 否定形より肯定形になっているか
4. CTA が1つだけか
5. ファーストビューで価値が伝わるか
6. 文字数が媒体規定内か
7. ブランドトーンと一致しているか
