# DCR Kernel Parallel Execution

並列実行の使用条件と禁止パターンを定義します。

## 使用条件（すべて満たす場合のみ）

1. 独立したタスクが 3 つ以上存在する
2. タスク間にデータ依存がない（出力が互いの入力にならない）
3. 各タスクの変更範囲が 1 ファイル以内
4. すべてのタスクが P1 または P2 に分類される

## 禁止パターン

- P3 操作を含む場合
- テスト → 修正 のチェーン（順序依存あり）
- 同一ファイルへの競合変更
- 失敗時に互いを汚染する可能性がある操作

## 適用例

```
ulw: [A ファイル編集] [B ファイル編集] [C ファイル編集]  → 並列可
ralph: テスト実行 → 修正 → 再テスト                      → 順次必須
```

判断が難しい場合は順次実行を選ぶ。並列を使う価値は速度であり、
正確性を犠牲にする価値はない。
