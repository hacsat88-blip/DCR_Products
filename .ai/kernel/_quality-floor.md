# DCR Kernel Quality Floor

完了宣言の必須条件を定義します。「動くはず」は完了ではありません。

## 完了の必須証跡

以下をすべて「今このセッションで実行した」結果として示すこと。キャッシュ・推測・以前の実行結果は不可。

1. **ビルド/コンパイル**: 対象言語の build コマンドが exit 0 で完了
2. **該当テスト**: 変更に関係するテストが pass（新規機能はテストを追加してから）
3. **Lint**: warning 以下（error がゼロ）

## 禁止表現

完了を偽装する言葉を使わない。

- 「should work」「probably」「seems to」「おそらく」「動くと思います」
- 「テストは通るはず」「問題ないはず」

代わりに: 実行した証跡（コマンドと出力）を示す。

## 検証不能な場合

検証できない理由を短く明示し、代替の確認方法を提案する。
「検証しました」とは言わない。
