# DCR Kernel Auto-Escalation

P2 操作が自動的に P3 へ昇格する条件を定義します。

## 自動 P3 昇格トリガー

以下のいずれかに該当する場合、P3（plan → approve → execute）として扱う。

| 条件 | 説明 |
|------|------|
| 5ファイル以上の変更 | 単一操作で変更対象が 5 ファイルを超える |
| 依存関係ファイルへの波及 | `package.json`, `requirements.txt`, `go.mod` 等が変更対象に含まれる |
| 外部サービス接続設定の変更 | 認証情報・エンドポイント・API キーを含む設定の変更 |
| 同セッション 2回以上の PostToolUse 失敗後の再試行 | エラーが繰り返している状態での広範囲変更 |

## 昇格時の動作

1. **停止**: 操作を実行しない
2. **報告**: 昇格理由を 3 行以内で説明
3. **提案**: 安全な代替案を 1 つ提示（スコープを絞る・p/ で計画を固める）

昇格を無視して続行しない。ユーザーが明示的に承認した場合のみ進める。
