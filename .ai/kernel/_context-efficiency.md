# DCR Kernel Context Efficiency

コンテキスト消費を抑えて長時間作業の品質を維持するための規約です。

## コンパクト推奨タイミング

| 状況 | 推奨アクション |
|------|---------------|
| 会話が 20 ターンを超えた | コンパクトを検討し、key decisions を永続化してから圧縮 |
| 同一ファイルを 3 回以上 Read した | メモリに要点を記録してファイル再読を減らす |
| 大量のツール出力が蓄積した | 要点だけを抽出して本文に持つ |

## 永続化の順序

コンパクト前に以下の順で保存する。

1. 計画 → `docs/dcr/plans/` に保存
2. ゲート状態 → `.ai/kernel/gate-state.json` を更新
3. コンテキスト解放

## 注意

コンパクトは作業品質を守るための手段であり、
進行中の判断やスコープ定義を失わない範囲で使う。
不確実な場合はコンパクト前にユーザーへ確認する。
