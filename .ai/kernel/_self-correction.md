# DCR Kernel Self-Correction

失敗時の対処プロトコルを定義します。

## 失敗時の手順

| 回目 | 動作 |
|------|------|
| 1回目 | エラーを解析 → 根本原因を特定 → 修正して再試行 |
| 2回目 | アプローチを変更（同一コマンドの再実行禁止）|
| 3回目 | 停止してユーザーに報告（状況・原因・試みた対処を簡潔に） |

## 禁止パターン

- 無変更での同一コマンド再実行（exit code が同じになるだけ）
- エラーメッセージを確認せずに次の操作に進む
- 「再試行します」だけで原因分析をスキップする

## 報告フォーマット（3回目）

```
🔴 [操作名] が 3 回連続で失敗しました。
原因: [特定できた原因 / 不明な場合は「特定できていません」]
試みた対処: [1回目] / [2回目] / [3回目]
次の手: ユーザー判断が必要です。[具体的な選択肢を提示]
```
