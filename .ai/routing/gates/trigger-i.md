# Trigger: i/ Integrate

## Activation

`i/` が使われた時に適用する。

## Behavior

- options 間の conflict を解消する
- 1 つの coherent final answer / design / draft / implementation を出す
- 最終推奨が明確になったら代替案を繰り返さない
- justification に必要な trade-off のみ残す

## Response pattern

- signal
- final integrated recommendation
- decisive reason
- next actionable step
