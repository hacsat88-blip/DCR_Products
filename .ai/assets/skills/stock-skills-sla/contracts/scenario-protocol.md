# Scenario Protocol — シナリオ枠契約

analyst / screener(value_growth) / strategist がシナリオを出す際に必ず従う構造。

## 期間別3シナリオ（必須）

シナリオ要求時（または投資判断を含む出力時）は、以下の3×3構造で出す。

### 期間軸（investment_horizon による）

| レンジ | 主な分析軸 |
|---|---|
| **1〜2年** (short_1_2y) | 決算進捗・業績修正・PER/PBR再評価・需給・直近IRカタリスト |
| **3〜5年** (mid_3_5y) | 中計・売上/利益CAGR・利益率改善・事業拡張・競争優位・資本効率 |
| **10年以上** (long_10y_plus) | 市場規模・複利成長・事業耐久性・参入障壁・経営資本配分・構造変化 |
| **multi** | 上記3レンジを横断比較 |

### シナリオ構造（各期間×3シナリオ）

各シナリオに以下を必須とする:

```
シナリオ: 上振れ / 中立 / 下振れ
想定レンジ:
  - 1〜5年: 株価または時価総額の %幅・倍率（例: +30〜+80%）
  - 10年以上: 時価総額・利益水準・評価倍率の到達条件
主要トリガー: （何が起きるとこのシナリオになるか）
成立条件: （必要な前提条件）
信頼度: 高 / 中 / 低
根拠強度: A（複数データ一致）/ B（一部推定）/ C（データ不足仮説）
主な不確実性: （このシナリオが崩れる要因）
```

## 下振れトリガー → Lesson リンク（α3）

下振れシナリオの「主要トリガー」には、過去の lesson.trigger に該当するものがあれば自動追記する:

```
⚠️[lesson-link] 過去事例: <lesson の trigger 要約>（<日付>）
expected_action: <lesson の期待行動>
```

## 信頼度ガイドライン

| 信頼度 | 基準 |
|---|---|
| 高 | 財務数値[E]・株価[W]・確定カタリストが揃っている |
| 中 | 一部推定軸あり（1〜2個）、主要数値は取得済み |
| 低 | 推定軸3個以上、または決算データが古い・欠落 |

## 10年以上シナリオの注意事項

- 価格目標ではなく「時価総額・利益水準・評価倍率の到達条件」として示す
- 根拠強度Cの場合は「要追加確認」枠に置く
- 過度な信頼度表現を避ける

## 価格目標の禁止

- 「○○円になる」「○倍になる」という断定的な価格目標を出さない
- 「想定レンジ」は条件付き推定として示す

## value_growth モード時の追加出力

- **10倍株シナリオの成立条件** を中立シナリオに埋め込む
  - 売上成長率（何年で何倍か）
  - 利益率改善（何%→何%）
  - 評価倍率の再評価（現PER→想定PER）
  - 時価総額拡大余地（現在→到達条件）
