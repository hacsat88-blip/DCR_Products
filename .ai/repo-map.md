# Main Directories

Repository governance model:
- Source layer: editable canonical assets (`rules/`, `skills/`, `templates/`, `.ai/agents-source/`)
- Runtime layer: tool entrypoints read directly by each editor (`.github/`, `AGENTS.md`, `CLAUDE.md`, `COPILOT_CLI.md`)
- Generated layer: deploy outputs and mirrors (`.cursor/rules/*.mdc`, `.claude/agents/`, `.codex/agents/`)
- Workspace layer: editor settings, docs, and operations scripts (`.vscode/`, `docs/`, `deploy.ps1`, `validate.ps1`, `init-project.ps1`)

Unsafe migration rule:
- Do not move `rules/` or `skills/` into `.cursor/`
- Do not delete `templates/` while `init-project.ps1` reads from it
- Do not overwrite runtime entrypoints from templates without an explicit migration plan
- Any future path migration must support old and new paths in parallel before deletion

## Execution layer (auto-loaded by each editor)

.github/copilot-instructions.md
VS Code Copilot entry point. DCR Kernel with Permission model (P1/P2/P3),
routing priority, and COPILOT_CLI.md reference.

AGENTS.md
Codex / Copilot CLI entry point. DCR Kernel + module behaviors.
Copilot CLI sessions redirect to COPILOT_CLI.md for full rule set.

COPILOT_CLI.md
GitHub Copilot CLI 専用の完全ルール定義。AGENTS.md から参照される。
Session initialization, tool hierarchy, permission model (P1/P2/P3),
SQL task tracking, error handling, completion verification を含む。

CLAUDE.md
Claude Code entry point. DCR Kernel + safety boundaries + permission model.

.ai/
AI system kernel, repo map, routing design, and behavior modules.

.ai/kernel.md
共通カーネル正本。全エディタの入口ファイルはこの思想を継承。

.ai/repo-map.md
このファイル。プロジェクト構造と規則の参照用。

.ai/rule-routing-design.md
ルール動的参照の設計文書。単一ソース原則、auto-load 安全条件、
エディタ別マッピングを定義。

.ai/module/
Specialized behavior modules (architecture, debugging, review, prompting).

.ai/kernel/gates/
Trigger-activated gate definitions (a/, i/, r/, s/, d/, p/, q/, sh/).
旧 `.commands/` は `.ai/kernel/gates/` に統合済み。

.cursor/rules/dcr-kernel.md
Cursor entry point. DCR Kernel + triggers (a/i/r/s/d/p/q/sh/) + Permission model +
Safety boundaries + Pipeline gate chain + module behaviors inlined.

.cursor/rules/*.mdc
Cursor agent rules + skills. deploy.ps1 が rules/*.md と skills/*/SKILL.md から自動生成。
rules は元ファイル名.mdc、skills は skill-<name>.mdc として出力。
生成物であり、source of truth ではない。手編集しない。

.vscode/
VS Code workspace settings (useInstructionFiles: true).
Workspace config layer。`rules/` や `templates/` の代替ではない。

## Deploy

deploy.ps1
一方向同期スクリプト。サトシ開発 → 各エディタのユーザーレベルパスへ配布。
- skills/ → ~/.agents/skills/ (VS Code Copilot)
- rules/*.md + skills/*/SKILL.md → ~/.cursor/rules/*.mdc + dcr-kernel.md (Cursor)
- .ai/agents-source/*.toml → .codex/agents/ (Codex)
- .ai/agents-source/*.md → .claude/agents/ (Claude Code)
オプション: -Target (all/vscode/cursor/agents), -DryRun, -Check (drift検出)。

sync-agents.ps1
レガシー: deploy.ps1 -Target agents に統合済み。互換性維持のため残存。

## Project Init

init-project.ps1
新規プロジェクト向け AI 指示ファイル生成スクリプト。
templates/ のテンプレートと project-context.md を入力に、
CLAUDE.md / AGENTS.md / .github/copilot-instructions.md の3ファイルを生成。
共有リソース (.ai/kernel.md, .ai/module/, .ai/kernel/gates/) もコピーする。
オプション: -ProjectPath (必須), -ContextFile, -Target (all/claude/codex/copilot), -SkipShared, -DryRun。

# Architecture Notes

Preferred layering:
copilot-instructions.md → kernel.md → module/*.md + .ai/kernel/gates/*.md

Configuration pattern:
Markdown-based instruction files, no code dependencies.

Deployment pattern:
deploy.ps1 syncs skills/, rules/, and agents to editor-specific paths.
One-way only: repository → editor. Never reverse.

# Change Rules

When modifying this repository:

- edit `rules/`, `skills/`, `templates/`, and `.ai/agents-source/` here, then deploy if needed
- prefer minimal diffs
- preserve existing naming conventions
- do not create files in templates/ unless archiving a new editor config or managing project init templates
- do not modify ~/.agents/ or ~/.cursor/ directly
- do not treat `.cursor/rules/`, `.claude/agents/`, or `.codex/agents/` as editable source paths
- do not perform one-shot move + overwrite + delete migrations for folder restructuring
