# DCR Supporting Documents

`docs/dcr/` は人間向けの補助文書と、必要な場合の cross-session plan / spec を置く領域です。
AI 構成の正本ではありません。現行の動作契約は `.ai/`、移行と検証の入口はルート `README.md` を参照します。

## 配置

- `plans/`: 継続が必要な計画
- `specs/`: 継続が必要な仕様
- `reference/`: Mac triad の補助リファレンス
- `architecture/`: 現行 adapter 構成の説明
- 各 `archive/`: 履歴専用。現行判断の起点にしない

Product 文書、旧 runtime の運用手順、machine-specific snapshot は置きません。
