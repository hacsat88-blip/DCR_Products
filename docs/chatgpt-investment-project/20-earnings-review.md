# 20 決算レビュー

## 目的

最新の決算を、株価反応やニュース見出しではなく、一次資料と前回の投資仮説に照らして評価する。

## 必要資料

必要な論点に応じ、次を使い分ける。

1. 最新の決算短信、決算説明資料、適時開示、企業IRはWeb検索で確認する
2. 有価証券報告書・半期報告書、構造化財務、セグメント、リスク等が必要ならEDINET系MCPを発火する
3. セグメント資料、KPI資料、質疑応答・説明会記録
4. 前期・前年同期の同種資料
5. 必要に応じて公的統計・市場データ

資料を取得できない項目は空欄を推測で埋めず、未確認とする。

株価反応だけを確認する場合はEDINET系MCPを発火しない。決算数値、会計上の注記、財務履歴、法定開示の文言が結論へ影響する場合は発火し、対象期間と文書種別を記録する。

## 1. 基準の確認

- 対象期間、会計基準、連結範囲、通貨、単位
- 決算発表日と価格反応の測定期間
- 会計方針変更、決算期変更、組織再編、株式分割
- 前回会社予想と市場予想の基準

成長率・利益率は元の金額から再計算する。会社独自KPIは定義変更の有無を確認する。

## 3. 事業の変化

- セグメント別の数量、単価、顧客数、解約、稼働率などのドライバー
- 売上増減と利益増減の橋渡し
- 受注、バックログ、在庫、運転資本
- 地域・製品・顧客構成の変化
- 成長が需要、価格、買収、為替のどれによるか

## 4. 利益の質

- 営業利益と営業CFの整合
- 一時利益・費用、補助金、資産売却、評価損益
- 株式報酬、リストラ、買収関連費用
- 売掛金、契約資産、在庫、引当金の異常
- 設備投資と減価償却の関係
- 実効税率、非支配持分、一株当たり利益への影響

## 5. 財務状態と資本配分

- 現金、負債、純有利子負債、満期、金利
- 配当、自社株買い、株式発行、希薄化
- M&A、設備投資、研究開発の進捗と成果
- 財務制限条項、偶発債務、保証、訴訟

## 6. 見通し

- 会社予想の変更点と前提
- 定量目標と、達成に必要な残期間の水準
- 経営者の説明が前回から変化した点
- 市場予想との差は参考情報とし、一次資料と混同しない

## 7. 投資仮説への影響

各項目を `強化 / 維持 / 弱化 / 反証 / 未確認` で評価する。

| 財務品質 | | | |
| 評価前提 | | | |

株価の上昇・下落だけを仮説の変化と判定しない。

## 8. 出力

1. 一言結論と証拠等級
2. 決算の主要サプライズ
3. 数値表と前年差・予想差
4. 利益・キャッシュフローの質
5. セグメント/KPI変化
6. 見通しと必要達成水準
7. 投資仮説への影響
8. 反対仮説
9. 次回確認事項とレビュー日
10. 出典表
